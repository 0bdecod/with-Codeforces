# with-Codeforces

Codeforces 문제 풀이를 기록하는 알고리즘 학습 저장소입니다.  
단순히 정답 코드를 모으는 것이 아니라, 문제 접근 과정, 실수, 개선점을 함께 정리하며 문제 해결 능력을 키우는 것을 목표로 합니다.

## 목표

- Codeforces Div.4 / Div.3 문제를 꾸준히 풀이
- 구현, 수학, 그리디, 문자열, 정렬, 브루트포스 기초 강화
- 문제를 읽고 조건을 정확히 해석하는 능력 향상
- 풀이 후 오답 원인과 개선 포인트 기록
- 장기적으로 Codeforces 800~1200 난이도 안정화

## 사용 언어

- C
- 과연 추가 될까?

초기에는 C 중심으로 풀이하고, STL과 알고리즘 활용이 필요한 문제부터 C++ 풀이를 병행합니다.
